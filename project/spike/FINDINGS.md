# Results 
The simulation that I mad for this project was not completely new, much of the code I made last week worked here, however, I changed my mind about what I wanted to simulate. Changing from the equilibrium simulation that I turned in last week I have moved to a orbital simulation which allows me to simulate sling shot orbits. Once getting to a point where I had something that I could have turned in last week I found a flaw. The projected path for the satellite was no were near accurate. This was due to me not simulating the orbit of the planet as a velocity Verlet in relation to it effects on the satellite. I decided to see how big a difference this change would make or if it was wrong from some bigger reason. After my testing in the spike file I found that It was indeed caused by this error.  This tells me that I can build a good simulation given the bounds that I have set for myself.
